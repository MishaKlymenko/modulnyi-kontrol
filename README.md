# Модульний контроль: HTML, CSS, Flexbox і Grid

Україномовний модульний контроль із 10 варіантами, таймером, переглядом HTML/CSS та автоматичним надсиланням відповідей у приватний GitHub-репозиторій через Vercel API.

## Запуск

Сайт розгортається у Vercel із цим репозиторієм. Для локального перегляду відкрийте `index.html`; надсилання робіт працює лише через розгорнутий Vercel API.

## Налаштування сховища робіт

1. Створіть fine-grained GitHub token із доступом лише до приватного репозиторію `MishaKlymenko/modulnyi-kontrol-results` і дозволом **Contents: Read and write**.
2. У Vercel у **Project → Settings → Environment Variables** додайте `SUBMISSIONS_GITHUB_TOKEN` із цим токеном.
3. Перевірте, що `SUBMISSIONS_ALLOWED_ORIGIN` має значення `https://modulnyi-kontrol.vercel.app` (це значення за замовчуванням) і повторно розгорніть сайт.

Після налаштування відкрийте приватний репозиторій `MishaKlymenko/modulnyi-kontrol-results` і переглядайте файли в `submissions/`. Кожна спроба зберігається окремим JSON-файлом. Токен ніколи не передається до браузера.

Після завершення студент бачить лише підтвердження надсилання, без балів. Якщо надсилання не вдається, сторінка явно повідомляє про помилку, дозволяє повторити спробу або завантажити JSON для передачі викладачу.

## Приватність

Роботи містять імена студентів та їхні відповіді. Репозиторій зі збереженими роботами має залишатися приватним, а доступ до нього слід надати лише викладачам, яким потрібно перевіряти роботи. Видаляйте дані відповідно до строків зберігання, установлених закладом освіти. Надсилання не є захищеним входом студента; обмеження повторної спроби в браузері можна обійти.
