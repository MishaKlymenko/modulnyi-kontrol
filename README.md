# Модульний контроль: HTML, CSS, Flexbox і Grid

Україномовний модульний контроль із 10 варіантами, таймером і попереднім переглядом HTML/CSS. Після завершення студент бачить лише повідомлення про успішне надсилання, без балів. Відповіді потрапляють у Google Sheets через Vercel API та Google Apps Script.

## Налаштування Google Sheets

1. Створіть Google-таблицю у вашому обліковому записі Google.
2. У таблиці виберіть **Розширення → Apps Script**. Замініть вміст `Code.gs` кодом із [`google-apps-script/Code.gs`](google-apps-script/Code.gs) і збережіть.
3. У редакторі Apps Script відкрийте **Налаштування проєкту → Властивості скрипту → Додати властивість**. Назва: `SUBMISSION_SHARED_SECRET`; значення — довгий випадковий секрет, який нікому не надсилайте.
4. У редакторі запустіть функцію `setupSheet` і надайте запитані дозволи. У таблиці з'явиться аркуш `Відповіді` із заголовками.
5. Виберіть **Розгорнути → Нове розгортання → Вебзастосунок**. Установіть **Виконувати як: Я** і **Хто має доступ: Усі**; натисніть **Розгорнути** та скопіюйте URL вебзастосунку, що закінчується на `/exec`.

Apps Script має бути доступним для анонімних викликів, щоб студенти могли надсилати відповіді. Секрет у властивостях скрипту відхиляє запити, які не пройшли через API цього проєкту. Якщо політика Google Workspace забороняє доступ «Усі», адміністратор домену має дозволити його.

## Налаштування Vercel

У Vercel відкрийте **Project → Settings → Environment Variables** і додайте для Production:

- `GOOGLE_APPS_SCRIPT_URL` — URL вебзастосунку Apps Script (`.../exec`).
- `SUBMISSION_SHARED_SECRET` — точно те саме значення, що збережене у властивостях Apps Script.

Після збереження змін повторно розгорніть проєкт у Vercel. Коли це буде зроблено, завершіть тестову спробу: у таблиці має з'явитися рядок на аркуші `Відповіді`. Повторне натискання надсилання оновлює цей самий рядок, а не створює дублікат.

У таблиці кожна спроба записується одним рядком: ім'я, варіант, дата, причина завершення, журнал втрати фокусу, п'ять теоретичних відповідей і два практичні завдання. У разі помилки сторінка не показує неправдиве підтвердження та дає змогу повторити надсилання або завантажити JSON.

## Приватність

Роботи містять персональні дані студентів. Обмежте доступ до таблиці викладачами, яким потрібно перевіряти відповіді; не публікуйте її за посиланням. Зберігайте дані лише стільки, скільки потрібно за правилами вашого закладу. Студентська сторінка не показує оцінок і не містить секретів. Обмеження повторної спроби зберігається у браузері, тож це не захист від обходу.
