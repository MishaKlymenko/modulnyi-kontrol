# Модульний контроль: HTML, CSS, Flexbox і Grid

Статичний україномовний модульний контроль із 10 варіантами, таймером, переглядом HTML/CSS та локальною перевіркою відповідей за критеріями.

## Запуск

Відкрийте `index.html` у сучасному браузері або опублікуйте репозиторій через GitHub Pages. Жодних залежностей, API-ключів чи серверної бази даних немає.

## Перевірка відповідей і дані

Оцінювання детерміноване: для теоретичних відповідей перевіряється наявність ключових понять і синонімів, а для практичних — ознак реалізації HTML/CSS-вимог. Показуються бали та критерії, яких бракує. Це попередня автоматична перевірка, не мовна модель: коректне нестандартне формулювання може не зарахуватися, а наявність ключових слів сама по собі не доводить правильність. Викладачеві варто переглянути відповіді та остаточно виставити оцінку.

Модуль працює повністю у браузері. Відповіді зберігаються лише в `localStorage` цього браузера; вони не надсилаються викладачеві чи на сервер. Результат можна завантажити як JSON. Обмеження повторної спроби прив'язане до браузерного сховища і не є захистом від обходу.

## Публікація

GitHub Actions автоматично публікує сайт у GitHub Pages після push до `main`.
